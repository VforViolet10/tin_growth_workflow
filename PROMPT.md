Run the community-question-radar skill using the project's existing context and the optional
focus. Find public conversations where the company's target buyer is actively asking for help
with a problem the product can genuinely address. Return only opportunities with a usable
public URL and enough evidence to understand the question.

Write reports/COMMUNITY_QUESTION_RADAR.md. The report must separate observed evidence from
interpretation, explain why each conversation is a fit, and give the founder a ready-to-edit
helpful reply. Do not publish, comment, send messages, create accounts, or contact anyone.
Do not invent product capabilities, customer results, quotes, dates, or conversation details.
If the search does not produce enough strong opportunities, report the shortfall rather than
padding the list with weak matches.
